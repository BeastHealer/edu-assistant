# FAQ. Технические вопросы

## Какое ПО нужно установить?
- Python 3.11 или 3.12
- JupyterLab или VS Code + расширение Jupyter
- Библиотеки из `requirements-course.txt` в LMS: pandas, matplotlib, seaborn, scikit-learn, jupyter

Опционально: Anaconda. На курсе достаточно официального Python + pip.

## Не открывается LMS / не грузится видео
1. Проверьте статус на status.edupath.example (учебный стенд).
2. Другой браузер (Chrome/Firefox), режим инкогнито.
3. Если сбой дольше 2 часов в день дедлайна — напишите в техподдержку LMS, сохраните скрин. Преподаватель учитывает массовые инциденты.

Куратор не сбрасывает пароли и не выдаёт доступы. Для логина/пароля — только техподдержка EduPath.

## Ошибка кодировки CSV
Попробуйте `encoding="utf-8-sig"`, затем `cp1251`. Не редактируйте файл в Excel «поверх», это часто ломает разделители. Разделитель на курсе — запятая.

## Ядро Jupyter не видит pandas
Вы установили библиотеку в другой интерпретатор. В ноутбуке выполните:
`import sys; print(sys.executable)`
и поставьте пакеты именно в этот Python.

## Можно ли сдавать в Google Colab?
Да, если ноутбук скачивается и открывается локально, а данные либо приложены, либо скачиваются ячейкой с фиксированной учебной ссылкой из LMS. Ссылки на личные Google Drive без доступа проверяющему не принимаются.
