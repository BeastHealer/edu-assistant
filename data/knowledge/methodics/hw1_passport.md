# Методичка. Домашнее задание 1: «Паспорт датасета»

## Цель
Показать, что вы умеете открыть таблицу, описать её и аккуратно посчитать базовые статистики. Это не конкурс на самый сложный код.

## Данные
Файл `shop_customers.csv` в материалах модуля M2 (вымышленные клиенты интернет-магазина «Северный свет», 1 200 строк). Поля: customer_id, age, city, orders_count, revenue, channel.

## Что сдать
Jupyter Notebook с разделами:
1. Загрузка и `info()`.
2. Пропуски и дубликаты.
3. Описательные статистики по `age`, `orders_count`, `revenue`.
4. Топ-5 городов по выручке.
5. Короткий вывод: 5–7 предложений.

## Ограничения
- Не нужно строить модели.
- Не нужно парсить внешние сайты.
- Код должен запускаться без ручных правок путей: используйте относительный путь `data/shop_customers.csv`.

## Критерии (преподаватель)
Зачёт / незачёт. Куратор оценки не выставляет. Ориентиры: ноутбук запускается, есть обработка пропусков, есть текстовый вывод, нет копипаста без понимания (преподаватель может задать уточняющий вопрос).

## Подсказки, если буксуете
- Сначала `df.head()` и `df.dtypes`, не начинайте с графиков.
- Для пропусков: посчитайте долю, решите удалять или заполнять, **напишите почему**.
- Для топ-5: `groupby` + `sum` + `sort_values`.
