# Лекция 3. Визуализация: как показать данные, а не украсить слайд

## 1. Принцип курса
График нужен, чтобы ответить на вопрос. Сначала формулируем вопрос, потом выбираем тип визуализации.

Примеры вопросов:
- Как распределён возраст клиентов? → гистограмма.
- Есть ли связь между стажем и доходом? → scatter plot.
- Какой регион приносит больше выручки? → bar chart.
- Как метрика менялась по неделям? → line chart.

## 2. Инструменты
- `matplotlib` — низкоуровневая библиотека, полный контроль.
- `seaborn` — удобные статистические графики поверх matplotlib.
- В ноутбуке: `%matplotlib inline` (в классическом Jupyter).

Минимальный шаблон:
```
import seaborn as sns
import matplotlib.pyplot as plt

sns.histplot(df["age"], bins=20)
plt.title("Распределение возраста")
plt.xlabel("Возраст")
plt.ylabel("Число наблюдений")
plt.show()
```

## 3. Правила оформления (проверяются в ДЗ-2)
- Есть заголовок и подписи осей на русском языке.
- Не используем pie chart, если категорий больше пяти.
- Цвет не несёт лишней семантики (не красим «просто красиво»).
- Если сравниваем величины, оси начинаются с нуля для bar chart.

## 4. Интерпретация важнее картинки
Под каждым графиком в ноутбуке должна быть ячейка Markdown: 2–4 предложения, что видно и какой вывод для бизнеса. Без интерпретации график не засчитывается.

## 5. Уровень сложности
Новичок: гистограмма, столбчатая диаграмма, scatter.
Продвинутый: facet/grid, boxplot для выбросов, аккуратная работа с цветовой палитрой и подписями выбросов.
