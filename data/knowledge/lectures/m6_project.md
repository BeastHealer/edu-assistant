# Лекция 6. Итоговый проект: от вопроса до презентации

## 1. Формат
Команды по 1–2 человека. Нужно пройти полный цикл: вопрос → данные → EDA → простая модель или аналитический вывод → рекомендации. Датасет — один из предложенных в методичке проекта либо согласованный с преподавателем заранее (не позднее недели 6).

## 2. Обязательная структура ноутбука
1. Введение: вопрос и гипотеза.
2. Описание данных и источники.
3. Очистка.
4. EDA с интерпретацией графиков.
5. Модель или расчёт (если модель не нужна, обоснуйте).
6. Ограничения и что бы вы сделали при наличии времени.
7. Вывод для «заказчика» на 1/2 страницы.

## 3. Критерии приёмки (напоминание)
- Воспроизводимость: ноутбук запускается сверху вниз.
- Есть ссылки на источники данных.
- Есть ограничения вывода.
- Презентация не длиннее 7 слайдов.

## 4. Защита
Онлайн-созвон 10 минут + 5 минут вопросы. Расписание слотов публикует преподаватель в LMS, куратор слоты не переносит.
