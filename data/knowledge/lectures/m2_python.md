# Лекция 2. Python, Jupyter и pandas: минимум, который нужен аналитику

## 1. Зачем Python
Python выбран как основной язык курса: много библиотек, понятный синтаксис, стандарт индустрии для аналитики. На курсе мы используем Python 3.11+ и Jupyter Notebook / JupyterLab.

## 2. Базовый синтаксис, который встречается в заданиях
- Переменные и типы: int, float, str, bool, list, dict.
- Условия `if/elif/else` и циклы `for`.
- Функции `def` — чтобы не копировать один и тот же код.
- Импорты: `import pandas as pd`.

Новичкам не нужно сразу учить объектно-ориентированное программирование. Достаточно читать чужой код в ноутбуке и менять параметры.

## 3. pandas: три объекта
- `Series` — один столбец.
- `DataFrame` — таблица.
- Индекс — подписи строк.

Типовой конвейер:
```
df = pd.read_csv("data.csv")
df.head()
df.info()
df.describe()
df.isna().sum()
```

## 4. Операции, которые нужны для ДЗ-1
- Выбор столбцов: `df[["age", "city"]]`
- Фильтрация: `df[df["age"] >= 18]`
- Новые признаки: `df["age_years"] = df["age_days"] / 365`
- Группировки: `df.groupby("city")["revenue"].mean()`
- Сортировка: `df.sort_values("revenue", ascending=False)`

## 5. Типичные ошибки студентов
- Забыть, что фильтрация возвращает **новый** DataFrame, исходный не меняется, пока нет присваивания.
- Путать `df["col"]` (Series) и `df[["col"]]` (DataFrame).
- Читать CSV с неправильной кодировкой. Для русскоязычных файлов часто нужно `encoding="utf-8"` или `encoding="cp1251"`.
- Вызывать `inplace=True` без необходимости — на курсе рекомендуем явное присваивание.

## 6. Критерий «достаточно хорошо»
Если вы умеете открыть CSV, посчитать пропуски, среднее и медиану, отфильтровать строки и сохранить результат — вы готовы к домашнему заданию модуля M2.
