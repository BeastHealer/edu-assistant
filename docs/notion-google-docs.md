# Как перенести документацию в Notion или Google Docs

Файлы в `docs/` специально плоские: заголовки, таблицы, нумерованные шаги — без зависимости от репозитория.

## Notion

1. Создайте страницу «ИИ-куратор EduPath».
2. Для каждого файла: Import → Markdown или вставка содержимого.
3. Рекомендуемая структура:
   - Архитектура системы
   - Архитектура промптов
   - RAG-схема
   - Регламент обновления базы
   - Аналитический отчёт (шаблон)
4. В Notion добавьте database «Документы базы знаний» с колонками как во frontmatter: `doc_id`, `module`, `resource_type`, `topic`.

## Google Docs

1. Файл → Открыть → загрузите `.md` или вставьте текст.
2. Вставьте диаграмму потока из `docs/architecture.md` как список или нарисуйте в Drawings.
3. Выдайте доступ команде курса: комментарии, не редактирование промптов «с телефона».

## Что не копировать в облако

Логи `data/analytics/queries.db` и любые будущие выгрузки с реальными студентами. В этом репозитории только учебные данные.
